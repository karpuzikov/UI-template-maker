# UI Template Maker

**TL;DR:** A single-file, dark-theme HTML tool for sketching UI layouts on a grid and exporting them as JSON that an AI can use as the base for element placement.

- Empty grid with adjustable resolution (columns × rows, cell px) and canvas presets (desktop, laptop, web, tablet, mobile).
- 100+ UI elements for **Web**, **Desktop** and **Mobile** apps — filter by platform or show all.
- Drag onto the grid, move, resize, layer (z-order), duplicate.
- Per-element attributes: text, font, size, weight, alignment, text/background colors, border, radius, opacity, shadow; image URL/alt/fit; input placeholder/value; toggle state; range values; list/table items; notes for the AI.
- **Export JSON** or **Copy for AI** (prompt + JSON with grid and exact pixel positions). Import JSON to continue editing. Autosaves in the browser.

**Use:** open `index.html` in a browser. No install, no build.
